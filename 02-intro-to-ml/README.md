# 02 : Introduction to Machine Learning



## What this chapter covers

The foundational ML course: how machines actually learn from data, and the
vocabulary you need for every chapter after this one.

- Machine Learning vs classical programming (rules vs learned rules)
- The full ML pipeline: raw data → preparation → training → evaluation →
  deployment
- Data quality and cleaning (missing values, outliers, duplicates) — often
  60-80% of real project time
- Features vs Labels, and the train/test split
- The 3 types of learning: supervised, unsupervised, reinforcement
- Supervised learning in depth: classification vs regression, worked examples
  (spam detection, house prices, customer segmentation)
- Overfitting vs underfitting, and the bias-variance trade-off
- Cross-validation (5-fold)
- The Python ML ecosystem: NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow,
  PyTorch
- The "10 commandments" of ML best practice, and common pitfalls

This is the conceptual backbone for the hands-on chapters that follow.
