# 05 — Classification II: Complete Course (All Models)



## What this chapter covers

A broader, self-contained classification course that revisits KNN and
Decision Trees and adds three more major algorithms, ending with a full
head-to-head comparison.

- Quick recap: KNN and Decision Trees (as in chapter 04)
- **Logistic Regression**: despite the name, a classification algorithm —
  the sigmoid function, how it outputs probabilities, and a worked numeric
  example
- **Support Vector Machines (SVM)**: maximum-margin separation, support
  vectors, and the kernel trick (linear, rbf, poly) for non-linear data
- **Random Forests**: combining many decision trees via bagging and random
  feature subsets, and why ensembles reduce overfitting
- Evaluation metrics recap: accuracy, confusion matrix, precision/recall/F1
- A full comparison table of all 5 models (KNN, Trees, Logistic Regression,
  SVM, Random Forest) across simplicity, performance, speed, and
  interpretability
- Normalization: which models need it and which don't
- Cross-validation (K-Fold) for more robust evaluation
- Practice exercises on the Wine dataset and hyperparameter tuning

This is the "which algorithm should I actually use?" chapter.
