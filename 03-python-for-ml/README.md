# 03 — Python for Machine Learning


## What this chapter covers

The hands-on toolkit chapter — everything needed to actually write ML code.

- Choosing a working environment (Google Colab recommended)
- **NumPy**: arrays (1D/2D/3D), shapes, broadcasting, indexing/slicing,
  vectorized math — and why it's 50-100x faster than plain Python lists
- **Pandas**: building and loading DataFrames, exploring data (`.head()`,
  `.describe()`, `.info()`), selecting with `loc`/`iloc`, filtering, grouping,
  handling missing values
- **Correlation**: what it means, how to read a correlation matrix, and why
  correlation isn't causation — illustrated on the Iris dataset
- **Matplotlib**: line plots, scatter plots, histograms, bar charts, box
  plots, subplots, and customization
- **Scikit-learn**: the standard workflow (load → split → fit → predict →
  evaluate), demonstrated end-to-end with a KNN classifier on Iris
- A reusable project template tying all four libraries together

By the end, you have the full toolchain needed for every ML chapter that
follows.
